# Tarrafa

O contrato de trabalho deste repositório está em **[`AGENTS.md`](AGENTS.md)** — leia antes
de instalar, executar ou alterar qualquer coisa. Ele define as tools, o CLI canônico, as
regras de sessão e os limites (material-only, nunca digitar senha, nunca commitar `.env`).

Pipeline de perfil de pessoa: [`docs/PROFILE_PIPELINE.md`](docs/PROFILE_PIPELINE.md).

Para ficar operacional fora deste repositório, rode `tarrafa skills install`: ele grava uma
skill com os caminhos desta máquina já resolvidos nos hosts de IA detectados.
